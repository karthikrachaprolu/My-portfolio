# Karthik Portfolio

Modern responsive portfolio for Karthik Rachaprolu.

## Run
Open `index.html` in a browser.

## Replace later
- `assets/images/profile.jpg` — profile photo
- `assets/images/project-*.jpg` — project images
- `assets/certificates/` — certificate files
- `resume.pdf` — resume
- `favicon.png` — favicon
- `og-image.jpg` — social sharing image
- Replace `#` social/GitHub links with actual URLs.

Font Awesome icons and Google Fonts are loaded through their public CDNs.
